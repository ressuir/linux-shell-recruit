# Task 02 Answer

## 1. 为什么 `./tools/recruit-info` 可以运行，而直接输入 `recruit-info` 找不到？

`./tools/recruit-info` 中的 `.` 表示当前目录，因此这里直接给 Shell 指定了程序文件的位置。

而直接输入 `recruit-info` 时，没有提供文件路径。Shell 会去 PATH 中记录的目录里依次寻找名为 `recruit-info` 的可执行文件。

`tools/` 目录默认不在 PATH 中，所以 Shell 找不到它。

## 2. 输入 `ls` 时 Shell 如何找到程序？

`ls` 本身对应磁盘上的一个可执行程序文件。

当输入 `ls` 时，Shell 会在 PATH 中记录的目录里依次寻找名为 `ls` 的可执行文件。

可以使用：

```bash
command -v ls
```

查看 Shell 实际找到的 `ls` 在哪里。
